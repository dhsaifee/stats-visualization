Interactive Descriptive Statistics and Distribution Visualization

Compute key descriptive statistics for a user-provided numeric dataset and visualize the distribution using a histogram and a box plot.

Descriptive Statistics

For a dataset with values \(x_1, x_2, \ldots, x_n\), the following metrics are calculated:

Count

\[ n = \text{number of observations} \]

Mean

\[ \mu = \frac{1}{n} \sum_{i=1}^{n} x_i \]

Median

\[ \tilde{x} = \begin{cases} x_{(n+1)/2}, & \text{if } n \text{ is odd} \\ \frac{x_{(n/2)} + x_{(n/2+1)}}{2}, & \text{if } n \text{ is even} \end{cases} \]

Population Standard Deviation

\[ \sigma = \sqrt{\frac{1}{n} \sum_{i=1}^{n}(x_i-\mu)^2} \]

First Quartile (25th Percentile)

\[ Q_1 = P_{25}(x) \]

Third Quartile (75th Percentile)

\[ Q_3 = P_{75}(x) \]

Interquartile Range (IQR)

\[ \text{IQR} = Q_3-Q_1 \]

Lower Whisker (Tukey Definition)

\[ \text{Lower Whisker} = \min\left\{x_i \mid x_i \ge Q_1-1.5\,\text{IQR}\right\} \]

Upper Whisker (Tukey Definition)

\[ \text{Upper Whisker} = \max\left\{x_i \mid x_i \le Q_3+1.5\,\text{IQR}\right\} \]

Visualizations

Histogram

Displays the empirical frequency distribution of the data with a user-controlled number of bins and adjustable bar spacing.

Box Plot

Summarizes the distribution using:

  • Median (central line)
  • Interquartile range (box)
  • Mean (diamond marker)
  • Whiskers defined by the \(1.5 \times \text{IQR}\) rule
  • Outliers shown as individual points

Together, these statistics and plots provide a concise view of central tendency, dispersion, distribution shape, and outliers.
